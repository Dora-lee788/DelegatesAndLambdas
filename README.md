## Вариант 1. Обработка чисел
1. List<int> numbers с произвольным набором положительных и отрицательных чисел.
2. Лямбда-фильтр Func<int, bool>: оставляет только чётные числа.
3. Лямбда-преобразование Func<int, int>: возводит число в квадрат.
4. Два лямбда-действия Action<int>, объединённые через += в один многоадресный делегат: одно выводит результат на экран, второе сохраняет его в отдельный список.
5. Конвейер: для каждого чётного числа вычислить квадрат и выполнить объединённое действие с результатом.

# Результаты и проверочные ключи
| Действие | Ожидаемый результат |
| :--- | :--- |
| отфильтрованные чётные | 2, 4, 6 |
| квадраты после преобразования | 4, 16, 36 |
| объединённое действие | значения выведены на экран И сохранены в списке (3 элемента) |

## Вариант 2. Обработка сообщений
1. List<string> messages с произвольным набором строк, включая пустые или слишком короткие.
2. Лямбда-фильтр Func<string, bool>: оставляет только строки длиннее 3 символов.
3. Лямбда-преобразование Func<string, string>: переводит строку в верхний регистр и добавляет префикс (например, "[LOG] ").
4. Два лямбда-действия Action<string>, объединённые через += в один многоадресный делегат: одно выводит результат на экран, второе сохраняет его в отдельный список истории.
5. Конвейер: для каждой подходящей строки выполнить преобразование и объединённое действие с результатом.

# Результаты и проверочные ключи
| Действие | Ожидаемый результат |
| :--- | :--- |
| отфильтрованные (длиннее 3 символов) | "привет", "до свидания" |
| после преобразования | "[LOG] ПРИВЕТ", "[LOG] ДО СВИДАНИЯ" (с вашим префиксом) |
| объединённое действие | значения выведены на экран И сохранены в списке (2 элемента) |
